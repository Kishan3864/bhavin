06Process

How an app gets shipped

Five stages, in order. From scope to store listing — the same route every app takes.

  1. 01Scope
  2. 02Architect
  3. 03Build
  4. 04Test & profile
  5. 05Release
  1. 01

    Scope

    What the app is for, who opens it, and which Android versions and devices have to be supported. Store policy is checked here, not at submission.

    01
  2. 02

    Architect

    Module structure, MVVM layers, data sources and navigation graph. Room schema and API contracts are agreed before a screen gets built.

    02
  3. 03

    Build

    Feature by feature in Jetpack Compose, wired through ViewModels and repositories. Coroutines and Flow for anything asynchronous.

    03
  4. 04

    Test & profile

    JUnit over the logic, manual passes on real low-end hardware, and the Android Studio Profiler on startup, memory and jank before release.

    04
  5. 05

    Release

    Signed bundle, Play Console listing, staged rollout, Crashlytics watched. Then the part most people skip — the updates after launch.

    05
